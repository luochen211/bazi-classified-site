# 比劫禄刃

来源：第一层级《3我抄的子平教材讲义第三节劫财，羊刃》。

入站页面：`/advanced/peer-rob-wealth`

本页承接第三节劫财、羊刃。已有十神基础页讲“比肩、劫财是什么”，十神细则页讲“过多、同柱、六亲定位”。本页进一步处理第三节里更实务的部分：劫财怎样才算重，建禄与羊刃如何区别，柱位年限如何落地，比劫什么时候真的能扶身。

## 四个判断原则

### 1. 先看是否值得重视

比劫不是一见就断。第三节强调，先看是否形成明显结构：

- 天干二见劫财，又通根于地支。
- 地支二见劫财，同时天干透劫财。
- 地支三合、三会比劫，天干再透比劫。
- 月支临官为建禄，阳日月支帝旺为羊刃。

这些才进入“过多、根深、根重”的判断。

### 2. 比肩、劫财不同性

比肩是同五行、同阴阳，性质较缓。

劫财是同五行、异阴阳，阴阳相扶，情切而速。它在利害场景里更容易迅速保护自己、争取细节、抓话柄、防损失。

### 3. 禄刃是特别格入口

比肩在月支临官，可成建禄。

阳日劫财在月支帝旺，可成羊刃。

建禄、羊刃都属特别格入口，有扶身与克财之性，但不能和普通比劫混成一句。

### 4. 扶身要有实际例式

比劫可以扶身，但不能只说“身弱喜比劫”。第三节给出的是具体例式：印格带财、官杀压力过重、日主需要同类帮身承压时，比劫才可能成为救应。

## 六个实务模块

### 劫财入式

劫财的重点不是一句“破财”，而是阴阳相扶后的行为模式。

无直接利害时，劫财重的人常有客气、试探、距离感和自信。进入生意、承诺、借贷、分利等利害场景时，则容易先问利益，再听细节；一旦发现吃亏，会迅速调整话术或抓住对方承诺中的漏洞。

判断时要分：

- 静态性格。
- 动态利害。
- 柱位年限。
- 六亲财务。

### 柱位年限

劫财在不同柱位，落点不同：

- 年柱：十五岁以前，多作家运不济、父缘薄、早年资源分夺看。
- 月柱：十六至三十岁，自以为是、立志过高、孤注一掷，婚恋和投资都要谨慎。
- 日支：不透出时多作家庭纠纷；若又透月时，内外忧患加重。
- 时柱：晚年重经济大权、房产存款和子女承接，只要资产仍在自己掌控，凶性较缓。

### 建禄与比肩

比肩不取比肩格，但月支为日主临官可成建禄。

建禄重点在祖业、财官承接和自立：

- 月令建禄而四柱无财官透出，或无财官禄旺，多主祖业难靠、白手起家、与家长不和。
- 四柱有财官透出，或财官有禄旺地支，且时干不透比劫，晚年可以主富。
- 月支建禄适合独立创业，不宜小规模一对一合伙。
- 建禄宜有官杀收束，使同类力量进入纪律和责任。

### 劫财羊刃

阳日主劫财坐月支帝旺，即是羊刃格。

羊刃与伤官有相似处：目光明亮、决心坚定、不轻易因人情压力改变信念，精于核算细节，对风险有防范意识。

羊刃要点：

- 基本喜忌：喜七杀，忌财地。
- 甲、戊、庚日羊刃逢冲多有祸；丙、壬日羊刃逢冲不作同等大祸。
- 忌地支相对、重见双刃、三合、三会。
- 年、时羊刃较重，月刃略轻，日刃更轻。
- 时上羊刃再见比刃，要看疾病和外灾。

### 比劫扶身例式

第三节反对空泛地说“比劫扶身”。可参考的实际入口包括：

- 印格带财，行比劫运可。
- 甲日子月，天干透庚七杀，需要比劫帮身。
- 丙日甲寅月，见正官、七杀，需要比劫帮身。
- 戊日午月，逢正官、七杀，需要比劫帮身。
- 庚日午月，见七杀，需要比劫帮身。
- 壬日酉月，见正官、七杀，宜比劫帮身。
- 癸日申月，见正官、七杀，宜比劫帮身。

这些例子共同指向：日主确实有承压问题，比劫才有扶身意义。

### 六亲财务

比劫本身可代表兄弟姐妹，但实务重点常在克财：

- 克偏财：牵动父亲、机会财、外部资源。
- 克正财：牵动妻星、稳定收入、现金流。
- 男命：财星既是钱也可代表妻星，婚姻与财务要合看。
- 月柱比劫重：三十岁前合作、投资、朋友同业、人情借贷容易带后遗症。
- 女命比劫合官杀：常因任性、自我、轻视伴侣或竞争关系引发困难。

## 四类对照

| 类型 | 判断重点 |
| --- | --- |
| 比肩 | 有理也肯让人，除大事外较能替人设想；但易因信人、好面子、拒绝困难留下后遗症。 |
| 劫财 | 得理不肯让，小事也会争；利害场景反应快，能防损失，也易招小人和冲突。 |
| 建禄 | 月令比肩临官，重自立和祖业承接。无财官多白手起家，有财官承接则可成福。 |
| 羊刃 | 月令劫财帝旺，重决断和防范。喜七杀来制，忌财地和冲刃，不能当普通劫财看。 |

## 五步流程

1. 看成重：是否天透地藏、二透一根、三合三会透干。
2. 分比劫：比肩较缓，劫财较速。
3. 定禄刃：月支临官为建禄，阳日帝旺为羊刃。
4. 查制化：建禄、羊刃宜官杀收束，尤其羊刃喜七杀。
5. 落问事：问财看合伙投资，问婚姻看财官被争，问健康看冲刃刑伤，问事业看竞争承压。

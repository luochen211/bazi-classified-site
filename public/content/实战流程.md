# 实战流程：从太极点到岁运应期

实战判断先立太极点：以日柱天干为日元，也就是命局里的“我”。所有十神、六亲、喜忌和事件，都要先回到这个中心点。

## 1. 定用神基调

先看日元在出生月令下的先天状态。

- 月令气候如何：寒、热、燥、湿。
- 日元是否有根、有生扶、有泄耗克制。
- 命局最需要的是调候、通关、扶抑，还是格局成用。

比如乙木生于夏初巳月，巳中丙火司权，烈日当空，环境焦燥。此时不能只说“木生火泄身”，还要先看木是否需要水润、湿土护根。壬癸水、辰土之类，才可能成为润局滋养乙木的喜用。

## 2. 看相邻干支

相邻干支决定具体影响怎么显出来：

- 天干透出，事情容易被看见。
- 地支藏干，事情多在暗线，等运年透出或冲开。
- 生克合冲落到十神，就是现实关系、经济帮助、感情亲疏和事件压力。

## 3. 四柱宫位

四柱为先天固定发展，可用“根、苗、花、果”理解。

| 宫位 | 主要含义 |
| --- | --- |
| 年干 | 父亲家族背景、祖父系祖，也可看 1-9 岁左右阶段。 |
| 年支 | 母亲家族背景、外祖父系祖，也可看 10-18 岁左右阶段。 |
| 月干 | 兄姊、同龄中年长者、同行前辈，约 19-27 岁阶段。 |
| 月支 | 弟妹、同龄中年幼者、同行后进，也是月令气候，约 28-36 岁阶段。 |
| 日支 | 夫妻宫，配偶性情、配偶家族、婚后经济能力与中年状态。 |
| 时柱 | 子女宫、晚年归宿与 55 岁之后阶段，时干偏长子女，时支偏次子女。 |

## 4. 原局、大运、流年

四柱原局是先天固定结构，大运是后天阶段气候，流年负责触发具体事件。

判断顺序：

1. 原局有什么伏笔。
2. 大运是否让某个主题成势。
3. 流年是否冲、合、刑、害、透出、填实。
4. 事件落在哪个宫位和哪个十神。
5. 用反馈复盘，不把断语当答案。

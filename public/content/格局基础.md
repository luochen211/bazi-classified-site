# 格局基础

来源：第一层级《4我抄的子平教材讲义第四节辅助教材》。

入站页面：`/advanced/pattern-foundation`

这一页承接第四节辅助教材。它不是直接讲富贵格，也不是让初学者一上来就争“身强身弱”，而是把会排盘之后必须检查的底层规则整理出来：特别格、得令得地得党、通根透藏、十干禄绝、日主无根、五种用神。

## 为什么需要这一页

会排八字、大运、十神、神煞、支藏天干，只是架子齐了。第四节特别提醒：别人看到你会排盘，会以为你懂命理，但真正判断还要继续看根气、透藏、刑冲合会、年限与问事落点。

所以本页放在八格总论之前，作用是：

- 防止把“身强身弱”当成唯一入口。
- 防止只看日主，不看财官印食杀伤自己的根气。
- 防止把特别格当成一见即断的标签。
- 防止把扶抑用神当成唯一用神。

## 四个基础原则

### 1. 会排盘不等于会判断

八字、大运、十神、支藏和神煞填完，只是完成了命盘表象。真正判断还要问：

- 关键天干有没有通根？
- 地支藏干有没有天透？
- 日主和格局十神是根重、根轻，还是无根？
- 刑冲合会落在哪个年限？
- 问的是婚姻、财运、事业，还是健康？

### 2. 强弱只是入口

得令、得地、得党是入门权宜。第四节指出，它脱离了调候、格局顺逆、六亲、年限之后，就容易变成瓶颈。

身强可以托财官，身弱不能托财官，这句话只能作为基础常识，不能替代后面的格局、调候和问事判断。

### 3. 每个十神都有根气

不只日主有强弱，正财、偏财、正官、七杀、食神、伤官、正印、偏印也都有自己的得令、得地、得党。

十神定位的实务，就是把每一类十神分别看：它是否透出、是否有根、是否被冲合、是否能在现实问题中起作用。

### 4. 用神不只一种

第四节把用神分成五个体系：

- 调候用神：处理寒暖燥湿。
- 格局用神：处理顺逆、通关、病药。
- 扶抑用神：处理日主过强或无根。
- 专旺用神：处理从旺、从势。
- 对应用神：处理具体问事，如健康、婚姻、家庭、财运。

## 六个核心模块

### 特别格三类

第四节把特别格分成三个方向：

1. 日主临官、帝旺类：如甲日月支寅为建禄，月支卯为羊刃。重点是月支才算。
2. 传统特别格：如魁罡、金神、三奇等。适合作为高阶识别，不先压过格局主线。
3. 全局、全生、全克类：如全局、全印、从杀、从儿等。要看全盘是否同向，不能只凭一两个字说从。

### 强弱瓶颈

得令、得地、得党原本是入门规则。第四节追溯到《三命通会》后指出：

- 得时更接近月令四时。
- 得地原义有地域意味，后人转成地支。
- 得党是后来的说法。

因此，它可作初阶认知，但不可久久困在这里。论命要再进入调候、格局、六亲和岁运。

### 通根透藏

通根与天透地藏是一组互看的术语：

- 天干有，地支支藏天干也有这个干，称为通根。
- 地支藏干在四柱天干中透出，称为天透。
- 合起来就是天透地藏。

日主可以通根，偏印、七杀、财星等格局十神也可以通根。格局成形常常要靠这一步。

### 十干禄绝

十干禄绝是判断根气和轻重的基础表。

| 天干 | 禄 | 绝 |
| --- | --- | --- |
| 甲 | 寅 | 申 |
| 乙 | 卯 | 酉 |
| 丙 | 巳 | 亥 |
| 丁 | 午 | 子 |
| 戊 | 巳 | 亥 |
| 己 | 午 | 子 |
| 庚 | 申 | 寅 |
| 辛 | 酉 | 卯 |
| 壬 | 亥 | 巳 |
| 癸 | 子 | 午 |

禄旺为根重；长生、余气、库为根轻。日主和格局十神都可分轻重。

### 日主无根

日主无根，不自动等于凶，也不自动等于不能托财官。

第四节给出关键分法：

- 日主无根，月支杀、财、伤当令，但不透干、不成局，容易形成凶象。
- 日主无根，月支杀、财、伤当令且透干，或三合成格，可能从势成局。
- 日主无根而财杀伤成格，另有劫财或比肩透出，容易变成不能从又不能扶。

### 五种用神

用神不是一个万能字。第四节强调，扶抑中和只是其中一层。

| 类型 | 解决的问题 |
| --- | --- |
| 调候用神 | 日主十干对四时月令的寒暖燥湿 |
| 格局用神 | 格局顺逆、通关、病药、成败 |
| 扶抑用神 | 日主过强、禄刃印俱有，或日主无根 |
| 专旺用神 | 全木全火等从旺，或日主无根、财杀当令之从势 |
| 对应用神 | 用户具体问健康、婚姻、财运、家庭等事项 |

## 从排盘到判断的五步

1. 先排架子：八字、大运、支藏天干、十神和刑冲合会要能完整排出。
2. 再查根气：日主和每个关键十神都查通根、天透、禄绝、轻重。
3. 分普通与特别：普通格局先走月令与天透地藏；特别格只在全局条件明显时启用。
4. 判能扶能从：日主无根时，不急着说弱，先看财杀伤是否成格、是否能从、是否被比劫破坏。
5. 接入问事：按婚姻、财运、事业、健康等问题，选择对应的用神和现实语言。
